* Cheatsheet Notes

** Glossary
+ Super = Windows button
+ PrtSc = Print screen button

** Action & Keybindings
|---+-----------------------------------------+---+-------------------|
| # | *System*                                | : | *Keybinding*      |
|---+-----------------------------------------+---+-------------------|
|   | _Menu_                                  |   |                   |
| + | app & search                            | : | Super+d           |

| + | show/hide Sway bar                      | : | Super+Shift+b     |
|---+-----------------------------------------+---+-------------------|

| + | move right                              | : | Super+Shift+l     |
| + | move down                               | : | Super+Shift+j     |
| + | move up                                 | : | Super+Shift+k     |
| + | close active window                     | : | Super+Shift+q     |
|   |                                         | : | Alt+F4            |
